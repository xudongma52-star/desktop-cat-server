# 首页模型加载优化（2026-10-08）

## 资源与效果

原始 `.traced.json`、PNG 和 Blender 源文件保留。发布使用 `src/assets/optimized` 中的独立资源，不再把数值数组嵌入场景脚本。

- 网格使用 Meshopt 无损编码，外层 gzip；不减面、不量化、不重排索引。生成脚本逐字节检查 Float32 属性与索引。
- 贴图保持原分辨率。WebP 解码后 RGBA 不一致的裁切图沿用 PNG，避免全透明像素 RGB 变化影响边缘采样。
- 蕨叶和左侧花枝原有根部延伸及法线重算在解码完成后执行；材质、光照、深度变形、阴影和迷雾公式沿用原实现。
- `pnpm --filter @desktop-cat/web pack:botanical` 重新生成资源和清单。资源经过 Vite 添加内容哈希，沿用现有静态文件缓存与发布路径。

## 加载阶段

先加载两只鸟、银杏和墙面贴图，首屏资源约 3,555,384 字节。文字按原节奏显露完成后开始计数，进度跟随首屏实际下载量；提交首帧后才到 100。

揭幕完成后使用两个并发槽加载其余植物。模型及贴图均就绪才显示对象，晚到对象用短淡入接入原迷雾。后台加载期间，自动显露只选择已就绪模型；完整加载后恢复原有全画面随机轨迹。

资源失败沿用简化画面提示，首屏队列结束后不无限等待；离开页面取消下载、监听和动画，释放已有纹理和几何。
