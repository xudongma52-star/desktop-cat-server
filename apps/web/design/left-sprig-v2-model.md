# 左侧五叶小花序：高清原色浅浮雕

本轮仅替换左侧五叶小花序植株。确认图保存为 `left-sprig-v2-approved.png`，原版本和其他已确认资产保留。

## 制作与参数

- 从确认图生成透明切出素材 `src/assets/left-sprig-v2-cutout.png`（724×2172），去除墙面及墙面投影；切出过程可能产生小幅边缘和颜色变化，不声称逐像素相同。
- Blender 5.2.2 LTS 实际执行 `build_left_sprig_v2.py`，保存可编辑的 `left-sprig-v2.blend` 和网页网格 `left-sprig-v2.traced.json`。
- 依据透明轮廓建立封闭薄壳，不使用矩形平面，也不以颜色亮度推算厚度。花序使用单像素采样保留细柄，大叶面采用两像素网格，纹理保持高清。
- 五叶分别配置中脉路径与宽度，沿生长方向组织腹部起伏和尖部轻卷；茎、叶柄、花簇共用像素映射与墙面锚点。
- 根部映射到原左侧位置，像素尺度为 .00303 模型单位；背壳厚 .003，起伏约 .005–.048 单位。这是设计尺寸，不是从照片测得的毫米参数。
- 最终网格 101514 顶点、203132 三角形。细叶脉和表面颜色由原图 UV 保存，不声称每条纹理都是独立几何。

## 原色和交互

取消这株植物的统一灰绿染色。单独关闭 ACES 色调映射，在完全显现时直接使用源图色彩，保留暖白、灰绿和卷面浅褐层次。其他材质与全站灯光未修改。

保留 referenceAnchor、深度场及 .12 整体抬升。用户指出本株及蕨叶茎尾悬空后，两株在网页加载时仅延长底部细柄到画面底边之外，UV 不变；上方叶片及花序坐标保持不变。两株共用新的根部阴影材质，在 y=-4.08 到 -3.55 之间将离墙高度平滑回落到锚点。可见网格与阴影网格使用同一变形，法线同时计入根部权重的梯度；其他植物继续使用原阴影材质。

当前页面按用户先前要求隐藏迷雾，呈现持续抬升状态，因此本轮验证的是实际静态投影，不能称为重新完成鼠标衰减三态验收。
