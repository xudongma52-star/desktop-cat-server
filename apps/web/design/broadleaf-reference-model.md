# 四叶木质弯枝：确认参考驱动的重建

本轮依据用户确认的四叶弯枝效果图，整体替换桌面中偏左的旧三出复叶单元，包括旧叶片、短叶柄、侧生小叶与旧主杆。其他植物与手机构图保持。

## 可继续编辑的源

- 参考原文件：`../src/assets/broadleaf-approved-reference.png`，1024×1536。
- Blender 5.2.2 LTS 脚本：`build_traced_broadleaf.py`。
- 打包原图的可编辑 Blender 场景：`broadleaf-traced.blend`。
- 网页网格：`../src/assets/broadleaf.traced.json`，37738 顶点、71680 三角形。
- 加载器：`../src/components/botanicalReferenceBroadleaf.ts`。

四片叶与合拢花苞分别按原图像素描边，保留独立的不对称轮廓。叶腹使用薄曲面，主茎、叶柄用连续变宽条带和原图木质纹理。枝节独立描边覆盖真实连接点；避免球形节点、直杆和花瓣式重复叶片。

像素到模型的统一映射为 x=-1+(pixelX-622)×0.0015，y=-1.25+(964-pixelY)×0.0015。主杆从原图底段继续弯曲，接回原植株根点 (-2.18,-4.55)。延长段 UV 采用同截面方向与渐变粗细，避开原图底端切面，消除接头切线与纹理方向差异。

## 网页外观与交互

沿用两朵花已验收的材质投影混合，独立图像资产，不修改其他植物材质参数。新网格的 referenceAnchor、法线梯度、可见顶点与阴影深度共用已有公式。原图自带光照；这是固定正面观看的投影外观与实际浮雕深度，不是恢复出的真实反照率或任意角度完整植物模型。

纹理加入桌面加载完成条件（6 项，手机仍为3项）；缩放跟随原场景；卸载释放新几何、材质、纹理及本组独立阴影材质。

后续按用户反馈加强动态投影：本组沿影响场的整体抬升由 .035 提高到 .12。可见材质与独立深度材质使用相同公式，法线梯度也同步补入 .12/botanicalLiftDepth；原图轮廓、UV、几何、其他植物及全站灯光保持。993×790 实测移动、静止2.6秒与移开4秒，移动时离墙投影明显，移开后恢复浅痕；截图为同目录 `shadow-moving.png`、`shadow-stationary.png`、`shadow-away.png`。

用户确认本组后，又要求银杏、主花与副花采用同样的抬起阴影：三组参考投影材质统一使用 .12 抬升及相应法线梯度，银杏与花朵的阴影深度同时更新。本组最终着色公式与确认版本一致，不再通过字符串把 .035 替换为 .12。模型、UV 和原图纹理经 SHA256 校验均未改变。993×790 页面实测银杏及两朵花的移动投影、静止2.6秒、移开4秒回落，浏览器无错误；类型检查与构建通过。截图：`ginkgo-shadow-moving.png`、`flowers-shadow-moving.png`、`flower-ginkgo-shadow-away.png`。
